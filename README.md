# Flap Trading：把 CONFIG 发给 AI，就能按授权买入

**复制一段话完成安装和首次配置，以后直接发送 Flap CONFIG 或预测 CA。**

适用于支持 `SKILL.md`、本地工具和 Node.js 的 AI 客户端。通过币安官方钱包工具执行 BNB Chain 交易；这是社区项目，不是币安或 Flap 官方产品。

## 1. 一次完成安装和配置

复制下面这段给 AI，按需修改 **0.1 BNB** 和 **1%**：

> 请安装 https://github.com/nopapername/flap-trading-skill 并按默认交易规则帮我连接钱包、完成设置。每笔最多 0.1 BNB，滑点 1%；以后发 CONFIG 或预测 CA，自动按预算内最高份额买入。

默认交易规则（v3）：允许预算内必要换币和经验证的已发行代币 BNB 直购；审计数据不可用时继续买入，无需再次确认；已明确的规则不重复询问。明确要求卖出后，自动仅将本次所得底池代币兑换成 BNB，原有余额不动。具体风险项、异常税、模拟失败或超出授权仍会停止。

接着按 AI 提示在币安 App 扫码、开启开发者模式。AI 确认设置完成后，就可以直接发 CONFIG，无需自己输入命令。

示例只有在你实际发送或确认后才成为授权，安装本身不会买币。Gas 另计；本金硬上限 1 BNB、滑点硬上限 5%。不需要的兑换或直购权限可另说“不允许”；卖出仍需另行要求。[详细设置](references/setup.md)

## 2. 以后直接发送 CONFIG

从 Flap 复制完整的 CONFIG 粘贴给 AI，或者发送预测代币地址即可。

首次授权为自动模式后，AI 在授权范围内连续完成解析、检查、必要兑换、后台模拟和买入，不再让你逐次确认交易预览。原生 BNB／ERC20 内盘按预算内最高允许份额购买；其他底池最多兑换一次，再按实际到账余额买入。已发行代币直购按明确授权的 BNB 预算执行。

成交确认后立即返回成交数量与交易哈希，随后由独立只读任务自动刷新全部已登记的当前持仓。归档对账较慢时先显示“持仓刷新中”，不会阻塞下一笔交易；AI 随后补上钱包余额、完整持仓表和本次实际盈亏报告，附快照时间。余额已核实为零的项目移到“历史持仓”，保留买入成本及可核实的已实现盈亏。读取失败不会被当成零余额隐藏。

| 币名和完整 CA | 持仓余额 | 买入成本（含 Gas） | 预计可卖价值 | 净盈亏 |
|---|---:|---:|---:|---:|
| 实际查询结果 | 实际到账 | 可核实成本 | 当前报价 | 可核实盈亏 |

你也可以直接说：“查询全部持仓”“检查刚才那笔交易为什么还没完成”“卖出指定代币的全部持仓”。卖出需要明确请求。选择默认规则 v3 后，明确卖出请求会连续完成卖出和本次所得兑换；原有支付币保持不动。未接受此规则的已有用户仍按原授权执行。

每次交易完成后都会展示当前 BNB 余额、已核实的剩余支付币余额和上表；全部卖完也明确显示空仓。卖出附本次实收 BNB、成本含 Gas、卖出及兑换 Gas、已实现净盈亏；买入或单独换币没有可核实的已实现盈亏时标为“不适用”或“未知”，不把持仓浮盈当成实际收益。查询失败如实标注，不用旧快照冒充当前余额。

净盈亏扣除持仓成本（含买入 Gas）及估算退出 Gas。其他底池的退出 Gas 可依据近期规范支付币合约调用回执、当前 Gas 价格和有限授权模拟估算，并清楚标注；这不是未来 DEX 路线模拟或费用上限。缺少样本、归档余额或成本证明时保留未知，AI 可只读对账并说明缺失证据。

查询持仓和成交后刷新时，Skill 会自动检查未知的 ERC20 买入成本，在当前节点缺少历史状态或限流时，尝试内置的 NodeReal、Blockmachine、Alchemy 公开归档端点。每个备用节点须通过链和冻结区块核对，再读取历史证据。能证明的成本自动保存并用于净盈亏；证据不足继续保留未知。已知成本不重复查询，离线快照不联网；缺失成本对账在独立统计进程进行，最多约两分钟，未变证据的失败会暂缓五分钟再试。

v0.1.4 合并同次操作的重复市场读取，并批量查询独立的身份与资产字段。兑换、授权、模拟、规范回执等必要步骤仍按依赖顺序执行；实际成交速度受钱包服务与链上确认影响。

### 什么时候会停下来？

超出授权、风险检查未通过、报价/模拟失败、钱包要求 App 确认或交易仍未查明时，会说明具体状态。重复发送同一个市场默认不会重复买入；不确定的交易先恢复，不重新下单。没有自动买入授权时，CONFIG 只进入查询或确认流程。

## 快速卖出与实际盈亏（v0.1.5）

首次接受默认规则 v3，或单独选择允许卖出后自动换回 BNB 时，AI 使用 `init --auto-sale-to-bnb` 保存此独立授权。随后只需说“卖出某币”，AI 核实币名与完整 CA，按已授权滑点连续卖出、核验实际所得、精确兑换成本次 BNB、确认回执。仍须明确卖出请求，不自动决定卖出时机。

交易结束后展示全部当前持仓表及本次卖出报告：实际份额、实收 BNB、买入成本含 Gas、卖出/兑换 Gas、已实现净盈亏。原生 BNB 收入采用交易级转移证明；节点不支持证明或原始成本不全时保留未知，后台只读补证。部分退款或失败不自动重复下单；中断沿同一父请求恢复。已领取/已发行资产的独立退出仍须明确授权，本版不自动 claim。
